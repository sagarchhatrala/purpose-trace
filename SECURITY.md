# Reporting security issues

Please report vulnerabilities privately to **chhatralasagar99@gmail.com** with
the affected version, a minimal synthetic reproduction, platform information,
and expected versus actual behavior. Do not send production secrets, private
customer data, API keys, or unredacted audit traces.

Version 1.x is the currently maintained line. There is no paid support contract
or guaranteed response SLA. Public issues are suitable for non-sensitive bugs.
Review [the security model](docs/SECURITY_MODEL.md) before relying on the tool's
bounded offline audit guarantees.
